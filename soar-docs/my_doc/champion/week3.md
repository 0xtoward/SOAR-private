# Week 3 — 曹议：精度稳定性 + NVFP4 + 数据集分析（三连冠，达成度 97%）

## 精度抖动问题
同样配置不同批次提交，正确性会抖动。每天 3 次机会，抖动 = 浪费。

## 基于 Logprob 的快速精度评测（核心工具）

### 为什么不用 MMLU？
- 首 token 准确率是"虚假繁荣"（翻转现象）
- 参考论文 "Accuracy is Not All You Need"

### 工具设计
**阶段一：采集基线（一次性）**
- BF16 模型 greedy 解码，提取最后 128 token 的 top-256 logprobs
- 按 BS=1/8/32 保存为稀疏基线（numpy，零 GPU 占用）

**阶段二：测试量化权重**
- 发相同 prompt，对比三项指标：KL 散度、余弦相似度
- 局限：只覆盖 Prefill 精度，不覆盖 Decode 误差传播

## 评测数据集分析
150 条，5 类各 30 条。关键发现：
- fwe/cwe 任务语义相关性低（随机单词、UUID）
- 校准数据应降低这部分比例，多用连续语义文本
- 过多随机数据对校准有负面影响

## NVFP4 量化（关键！）
- **评测机是 Blackwell GPU**
- NVFP4 = E2M1（1符号+2指数+1尾数），值域 [-6, 6]
- 双层缩放：每 16 权重共享 FP8(E4M3) 局部缩放 + 全局 FP32 缩放
- Blackwell 原生硬件加速，比软件 INT4 快
