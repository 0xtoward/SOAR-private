# Week 1 — 曹议：赛题初识、权重量化破局（91分，首冠）

## 评分公式
```
最终总分 = (S1×40% + S8×30% + Smax×30%) × C
```
- C < 97% → 0分（归零）
- C 97%-99% → 0.92
- C ≥ 99% → 1.0
- 每天仅 3 次提交

## 本地评测体系
设计了 3 组测试数据集：
- 0.1k-4k：短输入长输出（decode-heavy）
- 0.1k-0.5k：短输入短输出（延迟基线）
- 60k-0.5k：长输入短输出（prefill-heavy）

## 调参阶段
- 基线（默认配置）：~94分，accuracy 满分
- KV Cache FP8：三档有提升，总分 77-78（相对分在降）
- 在线 W8 量化：单并发无效，量化开销 > 带宽节省

## 关键转折：W4 权重量化
- 18GB → 5.4GB（压缩比 3:1）
- 单并发耗时降低约 40%
- 遇到模型适配工程问题

## 最终成绩
```json
{"C": 0.92, "S1": 100, "S8": 99.99, "Smax": 96.39,
 "final_score": 91, "performance_score": 98.91}
```

## 榜单
- 第1（曹议）：C=0.92，S1=100（最快）
- 第2-5名：C=1.0（满精度），速度接近

## 核心结论
- W4 量化是最大收益点（S1 权重 40%，带宽瓶颈）
- 但 C=0.92 离淘汰线太近，长期需要保精度
